# Test Project 
Основная цель проекта TestProj - обработка текстовых файлов и сортировка информации в 3 разных файла в зависимости от типов данных (Integer, Float, String).

## Особенности реализации
В процессе ревлизации проекта использовались:
JAVA: Java Development Kit version 21.0.5
IDE: IntelliJ IDEA Community Edition 2021.2.2
OS: Windows 10
Package builder: Apache Maven 3.9.8 и библиотека Apache Commons CLI 1.9.0
Rодировка файлов utf-8
Для запуска утилиты использовалась Windows PowerShell

## Инструкция по запуску проекта через IntelliJ IDEA
1) Запустить IntelliJ IDEA
2) Перейти на gitHub проекта и скопировать ссылку на проект 
3) Перейти File > New > Project From Version Control
4) В открывшемся окне выбрать Repository URL, вставить ссылку и нажать Clone
5) Нажать на Add Configuration. В открывшемся окне выбрать Класс Main
6) Загрузить входные файлы типа .txt в корень проекта. 
7) В этом же окне вписать в поле Program argument аргументы запуска программы (имена входных файлов и опции). Например: "-f  ИмяФайла.txt" . ВАЖНО!!! Для работы програмы необходимо ввести имя минимум одного входного файла.
8) Результат статистики будет выведен в консоль. По умолчанию программа сохраняет выходные файлы в корневую папку проекта, с именами integers.txt, floats.txt, strings.txt.

   Также IntelliJ IDEA можно собрать утилиту
Переходим в Build > Build Artifacts и выбираем Build, готовая утилита будет лежать в папке out\artifacts\TestProj_jar

## Инструкция по запуску утилиты
1) Запустить терминал. И перейти в распложение утилиты.
2) Переместить файл или файлы в расположение утилиты.
   Примечание: Файлы можно не перемещать, а при запуске утилиты указывать полные имена файлов. Например: C:\Java\TestProj\src\main\resources\in1.txt
3) Выполнить команду "java -jar TestProj.jar НАЗВАНИЕ_ВХОДНОГО_ФАЙЛА.txt", при необходимости добавив опции (Список опций приведен ниже).
ВАЖНО!!! Для работы програмы необходимо ввести имя минимум одного входного файла.

По умолчанию программа сохраняет выходные файлы в место расположения утилиты, с именами integers.txt, floats.txt, strings.txt. 

## Список опций
| Опция и параметры |                                                                    Описание                                         |
|------------------|---------------------------------------------------------------------------------------------------------------------|
|      -s      | Вывод краткой статистики о сортировке. Краткая статистика содержит колличество эллементов записанных в каждый файл                       |
|      -f      | Вывод полной статистики о сортировке. Полная статистика содержит колличество эллементов записанных в каждый файл, а также минимальное и максимальное значения для чисел и максимальную и минимальную длину строки для строк.| 
|      -a      | Параметр дополнения файлов. По умолчанию все выходные файлы перезаписываются, после введения этого параметра они дополняются.|
|-o [path] | Изменеие пути выходных файлов. По умолчанию все выходные файлы сохраняются в место расположения утилиты. |
|-p [prefix]|- Добавление префикса выходных файлов. По умолчанию программа сохраняет выходные файлы с именами integers.txt, floats.txt, strings.txt|
